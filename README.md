# Ondelio

Web pública de **Ondelio**, programa para Windows 10 y 11 que recupera archivos borrados, repara archivos dañados, copia discos que fallan y borra de forma segura.

Public website of **Ondelio**, a Windows 10 and 11 app that recovers deleted files, repairs damaged files, copies failing drives and securely erases data.
